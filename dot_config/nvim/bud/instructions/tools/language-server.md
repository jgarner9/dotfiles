## Language server (MCP: mcp-language-server)

Definitions, references, hover text and diagnostics from the project's
language server.

- Use `definition` to read the exact definition of a symbol.
- Use `references` before claiming something is unused.
- Use `hover` for types and signatures.
- Use `diagnostics` to check a file's current errors.

Read-only: never use its rename or edit tools.
