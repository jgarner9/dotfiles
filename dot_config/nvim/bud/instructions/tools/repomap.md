## repomap

Prints a ranked map of the repo: the most-referenced files first, each with its
top-level symbols. Bud already sends its output at the start of a chat in
`<repomap>`.

- Run `repomap -root . -max 80` through Bash if you need a deeper map.
- `repomap -json` gives the same data as JSON.

Use it to orient; then search or read specific files.
